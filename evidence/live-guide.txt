 ONBOARDING FLOW
Make your first connection in five minutes

Start with a safe read-only call. Once the AI client can see the tool catalog, configure approval rules for sensitive write operations.

01
Connect once

Use /mcp/troly for one connection. The server exposes only the tools included in the workspace plan.

02
Issue a credential

Use OAuth 2.1 + PKCE for ChatGPT or Claude Web, or create an MCP API key in the control panel for Cursor, VS Code, and Claude Code.

03
Test a read tool

Ask the agent to list tools, then run a read-only lookup such as finding an order or reading a conversation.

04
Set approval mode

Use Hybrid mode so messages, orders, posts, and other sensitive writes wait for workspace approval before execution.

Claude Desktop uses Connectors and OAuth. VS Code uses .vscode/mcp.json with the servers key. Cursor uses .cursor/mcp.json. Select your application in the admin page for its configuration.

.mcp.json (Claude Code)
Copy
{
  "mcpServers": {
    "trolypage": {
      "type": "http",
      "url": "https://trolypage.com/mcp/troly",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_API_KEY"
      }
    }
  }
}
Claude Code CLI
Copy
claude mcp add --transport http trolypage \
  https://trolypage.com/mcp/troly \
  --header "Authorization: Bearer YOUR_MCP_API_KEY"

 SECURITY & APPROVAL
Control every write requested by an AI client

Every external AI request is authenticated and bound to a workspace. Choose the approval policy that matches how your team operates.

Hybrid (recommended)
Default

Read-only calls and drafts run immediately. Sensitive writes such as publishing, broadcasting, creating orders, or creating shipments enter the workspace approval queue.

Strict
Maximum control

Every action that writes data must be manually approved by an operator before it can run.

Auto
Use with care

Tools run immediately when requested by the AI client. Use this only for well-tested agents and tightly controlled environments.

 TROUBLESHOOTING
Understand MCP HTTP errors

When an AI client receives an error from the MCP gateway, use this table to identify the cause and next action.

HTTP code	Cause and resolution
HTTP 401	The credential is missing, expired, or invalid. Sign in again through OAuth or create a new API key.
HTTP 402	The workspace plan does not include the requested MCP module. Upgrade the plan to enable it.
HTTP 403	The request is missing the mcp:use scope, has the wrong workspace context, lacks the required role, or uses a denied Origin.
HTTP 404	The MCP gateway is not enabled for this service, or the requested endpoint or resource does not exist.
HTTP 422	Tool arguments do not match the JSON Input Schema. Check the payload format and required fields.
HTTP 429	The workspace rate limit was reached. Wait for the duration specified by the Retry-After header before retrying.
