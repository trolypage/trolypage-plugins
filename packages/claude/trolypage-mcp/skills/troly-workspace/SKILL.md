# TrolyPage Workspace

Use only the `trolypage` MCP server. Read [tool-catalog.md](references/tool-catalog.md) for the available workspace and asset operations.

1. Resolve connected channels or agents with the available list tools; agent configuration and execution are outside this profile.
2. Read notifications before acknowledging or resolving them; these are different effects.
3. Search support tickets before creating a duplicate and inspect ticket state before replying.
4. Use existing or user-supplied assets. This profile has no AI media generation or arbitrary integration execution.
5. Verify changed state with a corresponding read tool. Do not expose credentials or claim that a ticket reply fixed its underlying issue.
